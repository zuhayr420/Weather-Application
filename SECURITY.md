# Security Policy

## Supported Versions

The following versions of Meridian Weather Application currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Meridian Weather Application seriously. If you believe you have discovered a security vulnerability, please do not report it in a public GitHub issue.

Instead, please submit a responsible disclosure report via GitHub Security Advisories:
- Navigate to the **Security** tab of this repository.
- Click **Report a vulnerability** to open a private disclosure draft.
- Alternatively, email `zuh1234ayr@gmail.com` with the subject line `[SECURITY] Meridian Vulnerability Report`.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Mitigation suggestions if available.

### Response Time
- **Acknowledgment**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Released via a patch release as soon as validated.
